# flmno site — editing guide

All copy, image URLs, and project data live in **one file**: `content.json`.
After editing it, run one command to rebuild the site.

---

## Workflow

```
1. Open content.json
2. Find the project you want to change
3. Edit the text / URLs
4. Run:  node build.js
5. Deploy (git push, or drag the folder to Vercel)
```

To rebuild just one project:
```
node build.js galen-tines-zine
```

---

```json
      "story": [

        "Second paragraph — displayed in sans-serif in the story sheet.",
        "Third paragraph."
      ],

      "meta": {

      },

      "gallery": [

```

---

## Field reference

| Field | Where it appears | Notes |
|---|---|---|
| `title` | Hero, browser tab, sheets | Required |
| `teaser` | Subtitle under the title | One sentence |
| `story` | Scroll-lit excerpt + full story sheet | Array of paragraphs. First = serif. |
| `meta` | Left column next to story | Any keys you like |
| `gallery` | Carousel, explore card, gallery sheet | Wix URLs, order matters |
| `related` | "More Work" horizontal scroll strip | 3–5 works best |
| `impact` | Impact cards section | `title` + `body` per card |
| `instagram_posts` | Instagram feed (social-media page only) | Array of post URLs |
| `stats` | Stat row (social-media page only) | `{ "value": "27", "label": "Posts" }` |

## Adding a new image

1. Upload to Wix Media Manager → copy the link
2. Paste into the `"gallery"` array in `content.json`
3. Run `node build.js your-project-slug`

The build script handles Wix's resize API automatically — you never touch URLs manually.

---

## Adding a new project

1. Add a new key under `"projects"` in `content.json` using a slug (e.g. `"new-project"`)
2. Fill in the fields
3. Run `node build.js` — the HTML file is created automatically
4. Add the project tile to `index.html`

---

## Files you should never manually edit

- `projects/<slug>/index.html` — generated by `build.js`, your changes will be overwritten next build
- `projects/case-study.css` — shared styles across all case study pages
- `projects/case-study.js` — shared interactions
